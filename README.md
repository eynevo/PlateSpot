# PlateSpot

Track license plates from US states, Canadian provinces, and Mexican states while driving.

## Features

- Spot plates with auto GPS location and timestamp capture
- Optional photos using your phone camera
- Interactive map of North America, color-coded by spotted regions
- Progress tracking with bars for US, Canada, Mexico, and overall
- Streak tracking for consecutive spotting days
- Search and filter sightings by region, date, or location
- Dark mode support
- CSV export for backup
- Works offline with IndexedDB local storage

## Usage

Open on your iPhone browser: https://eynevo.github.io/PlateSpot/

Add to Home Screen for an app-like experience.

## Development

```
npm install
npm run dev
```

## Deployment

Pushes to `main` automatically deploy to GitHub Pages via GitHub Actions.
